# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the workflow-orchestration-queue system.

## What is an ADR?

An ADR is a document that captures an important architectural decision made along with its context and consequences.

| ADR | Title | Status |

| ADR-001 | Polling-First Resiliency Model | Accepted |
| ADR-002 | Shell-Bridge Execution Pattern | Accepted |
| ADR-003 | Provider-Agnostic Queue Interface | Accepted |

## Creating a new ADR

1. Copy `adr-template.md` from `docs/architecture/`
2. Name it `NNNN-short-title.md` where NNNN is the next number
3. Fill in the sections
4. Submit for review
